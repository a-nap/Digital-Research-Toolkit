The tidyverse

In class, we used tidyverse functions over base R. The tidyverse is a curated set of R packages tailored for data science, all built around a consistent design philosophy, shared grammar, and common structures. They usually have punny names.

dplyr

dplyr is an R package in the tidyverse. It helps you work with data by providing you a set of simple, consistent commands that make it easier to do common tasks like filtering, sorting, and summarizing data.

ggplot2

I class, we have been using the ggplot2 and esquisse packages to visualize data. In this tutorial, you will practice plotting with the former package.

ggplot2 is a tool for making graphs. Its approach to data viz is that of a layered grammar of graphics. You design and construct graphics in a structured manner from data upwards. First, you tell it what data to use, how to match data to things like color or position, and what kind of shapes to draw (like bars or lines). Then ggplot2 builds the graph for you, handling the rest of the work.

We also practiced set theory. Set theory is a part of math and a way to thinking about groups of things and how they relate to each other. These “things” can be anything: numbers, letters, shapes, people, concepts, ideas, etc. We call these collections sets and each thing inside the set is called an element. Sets are useful because they allow us to analyze arguments using logic and structure, define categories (e.g. all living beings) and compare them (“some living beings are humans”). You can combine and compare sets by using unions (‘or’ |, so everything in A or B) and intersections (‘and’ &, so only what is in both A and B).

When you group data with group_by(), you’re putting it into categories based on one or more columns (like grouping people by age or cars by number of cylinders). Calling the grouping function does not change anything visibly but it changes the data “under the hood”.

14. Assignment and data input

In R, you can use three operators to assign values to a variable: ->, =, and ->>.

Operator Example Uses
<- and -> x <- 5 This is the traditional way of assigning values. You can read it as “Put 5 in x”.
= x = 5 This is similar to the operator above. It works fine in most cases and is usually used inside functions (like nrow(x = starwars)). You can read the example as “Set x equal to 5”.
->> and <<- x <<- 5 This is a special kind of <- operator: a “global assignment” operator. It assigns 5 to x in the global environment (outside the local scope), even if you’re inside a function. In lay terms, it makes the variable jump out of its environment and become global.

In this course, we use the -> operator for assigning global values (e.g. outside of functions) and the = operator for assigning values inside functions.

  • anti_join()

  mutate(
    Age = case_when(
      Name == "Catherine" ~ 5,
      Name == "Takeshi" ~ 8,
      Name == "Sven" ~ 8,
      Name == "Anouk" ~ 3,
      Name == "Amara" ~ 11,
      TRUE ~ Age           # Keep everything else as it is.
    ),
    School = case_when(
      Age >= 1 & Age <= 5 ~ "Preschool",
      Age >= 6 & Age <= 9 ~ "Primary school",
      Age >= 10 & Age <= 15 ~ "Middle school",
      TRUE ~ "Highschool"
    )) |>
  group_by(School) |>
  summarise(
    N = n(),
    Mean_Age = mean(Age)
  ) |>
  arrange(N)
