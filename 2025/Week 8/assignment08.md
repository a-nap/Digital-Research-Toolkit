# Assignment 08

In this task, you will export data relating to the Moses illusion and the noisy channel data sets. Upload a total of THREE files: PNG, PDF, and CSV.

Use the packages patchwork or cowplot to export the plots. Each file should consist plots of different kinds (6 plots overall in 2 files; e.g. no two point plots in file 1, no two bar plots in file 2, etc.).

## Task 1

Upload one PNG file with three plots visualizing the Moses illusion data. Use the tree different types of plot we spoke about in week 6 (or hybrid plots).

  1. Did you fall for the illusion? Show the correct answers per question type (% of correct answers in the illusion, control, and each filler type conditions).
  2. How did you do on the questions? Show the average accuracy per participant ONLY in two conditions: illusion and control (% of correct vs. incorrect answers; exclude don't knows).
  3. Which questions fooled the most people?  Show the average accuracy per participant ONLY in two conditions: illusion and control (% of correct vs. incorrect answers; exclude don't knows).

## Task 2

Export the preprocessed noisy channel data to CSV. Only clean the data, do not calculate summary statistics. You should have the preprocessing code already from a previous homework.

## Task 3

Upload one PDF file with three plots visualizing the cleaned and preprocessed noisy channel data. Use the tree different types of plot we spoke about in week 6 (or hybrid plots).

  1. Were all sentences created equal? Show whether there is difference in the total reading times for the whole sentence between all conditions.
  2. Did readers correct errors on the fly? Show the average reading times per sentence segment (also called interest area or IA) in both conditions.
  3. Were some participants fast or slow readers? Show the total reading time per participant.
